# Mortgage Camp fonts

Unmodified Latin WOFF2 webfonts from Google Fonts: Cormorant Garamond (normal and italic variable weight) and Lato (400 and 700). Font files are served locally so visitors do not contact a third-party font host. Copyright notices and SIL Open Font License terms are in CormorantGaramond-OFL.txt and Lato-OFL.txt.
